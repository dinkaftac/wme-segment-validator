# Changelog

## 0.12.0
- Sweep area can now be paused and resumed. Paused time is excluded from elapsed time and ETA.

## 0.11.0
- Merged `SELF_LOOP` and `TWO_SEG_LOOP` into one `LOOP` rule.
- Merged `UNNEEDED_NODE` and `STRAIGHT_NODE` into one `UNNEEDED_NODE` rule (on by default).
- `OVERLAP` now uses the shared overlap helper, including the elevation check.
- Rule filter drop-down now shows readable names grouped by category, with severity markers.
- `NEAR_MISS` label now states the real 10 m threshold.

## 0.10.0
- Initial version in this repository.
